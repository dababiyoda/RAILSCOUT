# RailScout Implementation Backcast

This document converts the 2026-08-19 RailScout doctrine into an implementation sequence.

Backcast rule:

> Define the strongest realistic end state, then work backward to the next irreversible or evidence-producing gate.

## End state

RailScout is a working AI Research Refinery that continuously discovers, designs, falsifies, ranks, validates, and packages Category-One infrastructure businesses.

It produces launch-ready assets, validation records, decision records, and commercial evidence while remaining bounded by the UNIIMENTE Kernel.

## Success condition

RailScout is working when a raw signal can move through this chain without losing evidence or founder intent:

```text
Raw Signal -> Evidence Record -> Claim Classification -> Stakeholder Map -> Opportunity Hypothesis -> Validation Test -> External Result -> Decision -> Launch Packet or Kill Record -> System Improvement -> Next Action
```

Prohibited without Kernel approval:

Completion evidence:

- every external effect routes through Kernel gates;

## Stage 8 - Full refinery operating cadence

Goal: RailScout becomes a repeatable founder operating system.

Minimum cadence:

- weekly raw-signal intake;
- weekly evidence classification;
- weekly opportunity ranking;
- weekly validation sprint planning;
- weekly decision ledger update;
- monthly doctrine/system improvement review;
- quarterly kill/retain/regress portfolio review.

Completion evidence:

- weak opportunities are killed;
- strong opportunities accumulate external evidence;
- reusable assets compound;
- founder time is leveraged;
- the system improves from its own failures.

## Kill criteria

Pause or regress RailScout implementation if:

- it produces more documents but no external tests;
- it duplicates Kernel authority;
- it confuses DALEOBANKS distribution with RailScout research;
- it treats model output as evidence;
- it loses negative results;
- it creates bureaucracy without decision-quality improvement;
- it grants autonomy without Kernel approval;
- it makes external claims without legal or evidence basis.

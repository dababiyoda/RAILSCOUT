## Lifecycle states

| State | Meaning |
|---|---|
| `active` | Authorized and currently binding within its stated scope. |
| `implemented` | Implemented with evidence or implementation references. |
| `deferred` | Intentionally postponed with a review trigger. |
| `superseded` | Replaced by a later, properly authorized intent. |
| `prohibited` | Preserved but barred by law, invariants, safety, or authority. |
| `exploratory` | Worth investigating, not executable authority. |
| `conflicted` | Materially conflicts with another intent or constraint. |
| `needs_evidence` | Cannot be resolved or activated without named evidence. |

## Authority levels

`aspiration`, `exploratory`, `advisory`, `active_requirement`, `delegated_authority`, `constitutional_invariant`, `external_constraint`, `unknown`

Authority must come from source and governance context. It must not be inferred from rhetoric, repetition, confidence, or model output.

## Extraction controls

- Preserve exact language when normalization could change meaning.
- Split compound prose into separate intents when components can have different states.
- Link derived intents to the same source without treating repetition as added authority.
- Preserve superseded, prohibited, negative, and conflicting records.
- Mark interpretation as inference; never present it as source text.
- Use `needs_evidence` when a factual premise controls disposition.
- Use `NEEDS_FOUNDER_DECISION` when authority cannot be resolved from inspected corpus.

## Upward interpretation rule

When an intention is ambiguous, interpret it toward the strongest lawful, evidence-preserving, human-sovereign, reversible, commercially durable, and participant-welfare-improving form.

"Build upward" never means:

- inventing evidence;
- bypassing founder authorization;
- granting machines sovereignty;
- converting aspirations into production claims;
- concealing downside;
- deleting rejected branches or negative results;
- increasing complexity without measured control advantage.

It means improving the architecture until its strongest useful property is retained with lower fragility, clearer authority, stronger proof, easier replacement, and better participant welfare.

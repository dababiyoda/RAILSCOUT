## Mandatory analysis frame

Use the recursive loop:

1. **Invert:** What failure does this prevent?
2. **Simplify:** What is the plain-English mechanism?
3. **Fuse:** What other mechanisms strengthen it?
4. **Stress:** How would a powerful adversary attack it?
5. **Compress:** What is the shortest usable operating rule?

Then build thoughts upward:

- map pros and cons;
- turn pros into stronger advantages;
- turn cons into design advantages;
- run exactly two explicit strengthening passes for material decisions;
- preserve dissent, counterevidence, zero results, and unresolved claims.

## Validation discipline

Never treat praise as validation. Valid validation requires at least one of:

- paid diagnostic;
- refundable deposit;
- prepaid pilot;
- signed LOI with specific success criteria;

- implementation discussion with authority.

- likes;
